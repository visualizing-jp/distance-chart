# distance-chart

距離で読み方が変わるグラフのデモです。

砂浜は、近くでは一粒ずつ大きさも色も違い、遠くでは一様な灰色に見えます。同じ見え方をグラフに当てはめました。

| 距離 | 見え方 | 読み方 |
|---|---|---|
| 近く | 一粒ずつ違う砂 | 1 粒 = 1 件 |
| 中間 | 一様な灰色のマスが並ぶワッフルチャート | 1 マス = 2,500 件 |
| 遠く | つながった 1 本の棒 | 棒の高さ = 件数 |

公開ページ: https://visualizing-jp.github.io/distance-chart/

## しくみ

- `index.html` の 1 ファイルだけで動きます。ビルドは不要です。
- 100 万粒を WebGL2 のフラグメントシェーダーで描いています。粒は頂点データとして持たず、画素ごとに「どの項目の何番目の粒か」を座標から求め、その番号のハッシュから大きさ・形・色を決めます。
- 粒が見分けられない距離では、粒とすき間の光の平均色を描きます。平均色は、同じ粒を実際に描いた画像をリニア光で平均して測っています。
- 数値は乱数で作った架空のデータです。

## 手元で開く

`index.html` をブラウザで開くだけです。WebGL2 が使えるブラウザが必要です。
